# SCREEN_SETTINGS.md — 設定画面

| 項目 | 内容 |
|---|---|
| ドキュメントID | SCR-SETTINGS |
| バージョン | v1.0 |
| 要件 | FR-701〜703, FR-104/105, 07(ロック) |
| 依存 | 03, 06, 07 |

## 1. 画面目的

プロフィール・店舗設定・同期状態・ストレージを一元管理する。

## 2. UI構成

```
① プロフィール: 名前/メール/ロール表示、パスワード変更(リセットメール)
② 店舗（manager+）: 店舗名/住所/査定書ロゴ(画像選択)/スタッフ管理(招待・無効化 FR-104)
③ 同期: 状態(✓最新/⟳同期中/⚠️N件失敗)、キュー一覧、[今すぐ同期][失敗を再送](FR-702)
④ ストレージ: 使用量(原本/マスク済/キャッシュ内訳)、[キャッシュ削除](FR-703)、原本自動削除期間設定
⑤ セキュリティ: Face IDロックON/OFF(店舗強制時はロック表示)
⑥ その他: バージョン/ライセンス/ログアウト
```

## 3. 状態遷移

セクション毎に独立 loading/content/error。ログアウトは確認ダイアログ→未同期件数がある場合は強い警告。

## 4. ViewModel 責務（SettingsViewModel）

- 各セクション状態、SyncService.queueStatus 購読、ストレージ計測（FileManager集計をバックグラウンド）
- スタッフ招待: メール入力→CF招待関数呼び出し（メールリンク）

## 5. Service 責務

- AuthService（プロフィール/リセット/ログアウト）、SyncService、StoreService（店舗設定・ロゴStorageアップ）

## 6. Firestore 更新

- 店舗設定/スタッフ書き込みは manager+ のみ（Rules二重強制）。ロゴは Storage `stores/{id}/assets/logo`。

## 7. SwiftData キャッシュ

- キャッシュ削除は synced 済データのみ対象。未同期(pending/failed)は削除不可（データ消失ゼロ NFR-04）。

## 8. Gemini / 9. Vision

- なし。

## 10. エラーハンドリング

- 招待失敗（既存メール等）は文言別表示。ログアウト時の未同期警告は件数明示。

## 11. アニメーション

- 同期状態アイコンの回転/チェック遷移のみ。

## 12. Liquid Glass デザインルール

- 標準 grouped リスト基調。ガラスは同期状態カードのみ。

## 13. アクセシビリティ

- キュー件数・失敗はバッジ+読み上げ。破壊的操作（キャッシュ削除/ログアウト）は確認必須。

## 14. テストケース

| ID | ケース | 期待 |
|---|---|---|
| SCR-SET-01 | staff で店舗セクション | 非表示 |
| SCR-SET-02 | 失敗3件→再送 | キュー再実行・成功で0件 |
| SCR-SET-03 | 未同期ありでキャッシュ削除 | pending分は保持される |
| SCR-SET-04 | 未同期ありでログアウト | 警告に件数表示 |

## 15. Claude Code 実装指示

1. ストレージ集計は actor でバックグラウンド実行、キャンセル対応。
2. スタッフ管理はM8。CF招待関数はスタブ→後結線。
