# Checker-S

スマートフォンのカメラで撮影するだけで、AIが **傷・凹み・修復歴** を判定し、中古車の査定を瞬時に提示するモバイルWebアプリ（PWA）です。

## 🌟 主な機能

- **アカウント機能** - 新規登録 / ログイン / ログアウト（localStorageベース）
- **車両情報入力** - メーカー9社・車種50以上 + 年式 / 走行距離 / カラー / ミッション
- **ガイド付きカメラ撮影** - 8箇所の指定アングルで、画面上に**青い枠組みフレーム**を表示し、それに車を合わせて撮影
- **AI解析** - 撮影画像の特徴量を基に傷・凹み・修復歴・錆・塗装劣化・内装の汚れ等を検出
- **査定金額算出** - 基準価格×年式×走行距離×ミッション×カラー×市場係数 − ダメージ控除
- **見積書PDF** - ワンタップで **PDFダウンロード** / **Web Share APIで共有**（LINE・メール等）
- **履歴保存** - 過去の査定結果をホーム画面から再表示
- **オフライン対応** - Service Worker により主要アセットをキャッシュ

## 🚀 使い方

1. スマホで `index.html` を開く（HTTPS推奨・カメラ権限が必要）
2. 新規登録 or デモアカウント（`demo@checker.jp` / `demo1234`）でログイン
3. 「査定を開始」→ 車両情報を入力
4. 撮影ガイドに従い8箇所を撮影（フロント/リア/左右サイド/ボンネット/ルーフ/運転席/メーター）
5. AI解析を実行 → 査定金額・ダメージ一覧・内訳が表示
6. PDFをダウンロード or 共有

## 🏃 ローカル実行

```bash
# 任意の静的サーバでOK
npx serve .
# または
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開く。スマホから実機確認するにはHTTPSが必要（カメラAPIの制限）。

## 📁 ファイル構成

```
├─ index.html            # 画面マークアップ（6ビュー統合）
├─ manifest.json         # PWA マニフェスト
├─ service-worker.js     # オフラインキャッシュ
├─ css/styles.css        # モバイル向けダークテーマ
├─ js/
│  ├─ data.js            # メーカー/車種/撮影手順/年式
│  ├─ auth.js            # ログイン/登録 (SHA-256)
│  ├─ camera.js          # getUserMedia + 撮影
│  ├─ ai.js              # AIモック + 査定計算エンジン
│  ├─ pdf.js             # jsPDFでの見積書生成 + 共有
│  └─ app.js             # 画面遷移・フォーム・フロー結線
└─ assets/icons/icon.svg # アプリアイコン
```

## 🔒 セキュリティに関する注記

デモ目的のためパスワードはブラウザのSubtleCryptoによるSHA-256ハッシュ + ソルトで
localStorageに保存されています。本番では必ずサーバー側認証（bcrypt/argon2 + HTTPS）に
置き換えてください。
